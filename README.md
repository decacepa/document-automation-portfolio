# Document & spreadsheet automation — portfolio

I build the scripts that handle repetitive document work: scanned PDFs renamed to a strict
standard and compressed under a hard size limit, dozens of spreadsheets merged into one file that
actually reconciles, and bots that watch a source and only speak up when something matches.

Three working projects, each one runnable end to end in under a minute.

---

### [01 — PDF batch processor](01-pdf-batch-processor)

Reads the record ID off page 1 of each scanned PDF, renames the file to a four-part standard and
compresses it below 400 KB. Files it cannot read are quarantined, never guessed.

`437 KB → 252 KB · a full day of manual work → under a second per file · zero naming errors`

**Python · pypdf · reportlab · qpdf**

---

### [02 — Spreadsheet consolidator](02-spreadsheet-consolidator)

Merges individual claim sheets into one master workbook with live formulas, and flags every blank
cell, text-typed number and duplicate row on a separate Issues sheet instead of absorbing it into
the total.

`12 files → 124 rows · 3 defects caught · 0.1s`

**Python · openpyxl**

---

### [03 — Monitoring bot](03-monitoring-bot)

Watches a source on a schedule, applies criteria from a config file a non-technical user can edit,
persists what it has already reported and never sends the same alert twice.

**Python · JSON config · persistent state · full logging**

---

## How these are built

The same four decisions run through all three:

**Rules live in `config.json`, never in the code.** A new client with a different standard needs a
new config file, not a new script.

**Nothing is guessed.** When input does not match the rules, the pipeline stops and names the
file, the row and the reason. Silent success on bad data is the expensive failure.

**Everything is logged.** Every run leaves a timestamped record of what was processed and what
was rejected, so the batch can be audited after the fact.

**The client keeps the tool.** Each project ships with the config and a README in plain English,
so it can be rerun without me.
