PDF pipeline

29 scanned documents, one strict standard

Problem
Each scanned PDF belonged to a different person, had to be renamed to a four-part standard, and was rejected by the archiving system above 400 KB.
Build
Python script that reads page 1, extracts the ID, assembles the filename from ID, year, term and document code, then compresses until the file fits — without losing readability.
Result
A full working day reduced to under two minutes. Zero naming errors across the batch.

Excel consolidation

Dozens of individual sheets into one master report

Problem
One spreadsheet per person, rebuilt every cycle into a single report where the totals had to reconcile exactly. One wrong cell invalidated the whole file.
Build
Automated consolidation with validation rules that stop and flag a missing or malformed row rather than passing it through.
Result
One master file, rebuilt in minutes, with every discrepancy surfaced before submission.

Monitoring bot

Rules in a config file, not in the code

Problem
A source that changes constantly, where only a narrow set of conditions is worth acting on — and checking manually means missing them.
Build
Python bot reading its criteria from an external config.json, so the rules can be changed without touching the code, with a full log of every check.
Result
Runs unattended in production and catches matches that manual checking missed.
